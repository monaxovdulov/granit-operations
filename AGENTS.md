# Правила работы Codex в `granit-operations`

Этот файл загружается автоматически. Держи его коротким: подробности находятся
в документах по ссылкам ниже.

## Общий порядок

Перед изменениями прочитай:

1. `README.md`;
2. `docs/source-of-truth.md`;
3. `docs/AGENT_WORKFLOW.md`;
4. документ текущей задачи;
5. относящиеся к задаче ADR и архитектурные документы.

Сохраняй чужие незавершённые изменения. Не считай исторический план или старый
отчёт проверки действующим источником истины без сверки с текущим SHA, кодом и
принятыми ADR.

## Рефакторинг AI-слоя

Для проектирования, реализации или проверки рефакторинга AI-слоя обязательно
прочитай:

- `docs/AI_AGENT_REFACTOR_PLAYBOOK_RU.md`;
- текущий документ среза, созданный по
  `docs/tasks/AI_REFACTOR_SLICE_TEMPLATE_RU.md`.

Первая будущая техническая задача — сверка противоречивого исходного состояния
AI-слоя. Не начинай реализацию новой архитектуры, пока эта сверка не получила
воспроизводимые доказательства.

## Неподвижные правила

- Одновременно активен только один срез с одним видимым результатом.
- Один запуск выполняет одну роль.
- Следующий срез не начинается автоматически.
- Субагенты, Multi-agent, Terra и Ultra запрещены.
- Архитектор, Исследователь кода, Проверяющий и Учитель не меняют рабочий код.
- Рабочий код меняют только Исполнитель и запуск Исправления.
- Автор изменений не принимает собственную работу.
- Возникшая архитектурная развилка возвращается Архитектору.
- Соседняя работа записывается как кандидат следующего среза и не выполняется.
- После достижения критериев успеха дополнительная полировка запрещена.
- Следующий срез заблокирован до статуса `understanding_verified`.

## Распределение моделей

| Роль | Модель | Назначение |
|---|---|---|
| Архитектор | GPT-5.6 Sol, обычно `medium` | Исходное состояние, варианты, решение и контракт среза |
| Исполнитель | GPT-5.5 `xhigh` | Реализация утверждённого контракта |
| Исследователь кода | GPT-5.4 `high` | Свежий поиск пропущенных проблем только по коду |
| Проверяющий | GPT-5.6 Sol | Независимая техническая проверка |
| Исправление | GPT-5.5 `xhigh` | Только подтверждённые замечания прежней области |
| Учитель | GPT-5.6 Sol | Проверка понимания владельца |

Модель выбирается до запуска и не меняется внутри него. Если нужная модель
недоступна, остановись и сообщи владельцу; не подменяй её молча.

## До записи рабочего кода

В документе среза должны быть одобрены:

- один результат и критерии успеха;
- источники истины и исходный SHA;
- область работы и явные исключения;
- разрешённые файлы и модули;
- лимит файлов и ориентир строк рабочего кода;
- обязательные проверки и доказательства;
- условия остановки;
- последовательность ролей;
- контрольный список понимания.

Если нужен неутверждённый файл, модуль, контракт, миграция, промпт, инструмент,
настройка модели, правило приватности или другой репозиторий — остановись.

## Перед завершением технической роли

Зафиксируй:

- исходный и итоговый SHA;
- полный список затронутых файлов и `git diff --stat`;
- область прямого и косвенного влияния;
- выполненные тесты, проверку типов, сборку и применимые оценки;
- непроверенные области;
- способ отката или безопасного отказа от изменения.

Невыполненная проверка означает `needs_evidence`, а не успешный результат.
